# Проектирование информационной системы "Университетская спартакиада"

Данный репозиторий содержит UML-диаграммы, разработанные в рамках проекта по проектированию информационной системы для управления университетской спартакиадой.

## Описание проекта

Информационная система "Университетская спартакиада" предназначена для автоматизации процессов организации, проведения и учета результатов спортивных соревнований между студентами университета. Система позволяет управлять командами, участниками, соревнованиями, результатами и рейтингами.

## Задачи проекта

1. Построить диаграмму сценариев UML для информационной системы.
2. Построить диаграмму классов UML для программного обеспечения:
- Диаграмма классов объектной базы данных;
- Диаграмма классов пользовательского интерфейса.
3. Построить диаграммы деятельности UML, описывающие алгоритмы работы методов классов.
4. Построить диаграммы последовательности UML:
- Описывающие сценарии работы информационной системы с участием Актера;
- Описывающие алгоритмы обработки данных без участия Актера.
5. Построить диаграммы компонентов и топологии.
